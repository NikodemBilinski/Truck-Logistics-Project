# Truck Logistics Project

# About

Full-stack logistics management system built with .NET. </br>
The system enables efficient managment of Users, Trucks, Transport Jobs, Clients and Invoicesthrough a desktop client communicating with a server.

# Architecture

The Project follows a Client-Server model:

<li style="margin:15px; font-size:20px">Server: ASP.NET Core Web Api (Rest API)</li>
<li style="margin:15px; font-size:20px">Client: .NET MAUI (Multi-platform App UI) </li>
<li style="margin:15px; font-size:20px">Database: SQL Server / Entity Framework Core</li>
<li style="margin:15px; font-size:20px">Database GUI: SQL Server Management Studio 22</li>
